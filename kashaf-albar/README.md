# كشّاف البر — مشروع أولي قابل للتطوير

تطبيق عربي (React Native + Expo) لدليل الحياة البرية، مصمم للعمل الميداني. تتضمن الواجهة دليلًا محليًا تجريبيًا، والبحث، والمفضلة، وسجل اكتشافات محفوظًا محليًا عبر SQLite، ومحرك تصنيف صور عام على iOS باستخدام Apple Vision يعمل على الجهاز.

## وظائف موجودة في هذه النسخة
- واجهة عربية واتجاه RTL وتصميم مستوحى من الصحراء.
- فتح الكاميرا أو اختيار صورة من مكتبة الصور.
- نسخ الصور المختارة إلى مجلد التطبيق الخاص قدر الإمكان، ثم حفظ سجل الاكتشافات محليًا.
- حذف سجلات الاكتشافات.
- دليل تجريبي محدود مع بحث عربي/إنجليزي/علمي.
- مفضلة محفوظة محليًا باستخدام SQLite.
- واجهة تعرض حالة الحزم بوضوح دون الادعاء أن حزمًا أو نماذج غير موجودة قابلة للتنزيل.
- معالجة أساسية لأذونات الكاميرا والصور والأخطاء المتوقعة.

## دمج محرك Core ML المتخصص (نقطة تكامل)
- وحدة iOS تتحقق من وجود نموذج Core ML متخصص محلي باسم `KashafSpecies.mlmodelc` أو `KashafSpecies.mlmodel` تحت `Library/Application Support/KashafModels/` وتستخدمه إذا كان مثبتًا.
- إذا لم يكن النموذج موجودًا، تعود إلى Apple Vision العام وتوضح الواجهة ذلك للمستخدم.
- **أوزان النموذج المتخصص غير مضمنة في المشروع بعد**؛ لذلك لا يعتبر التعرف على الأنواع المتخصصة مفعّلًا حتى يتم توفير نموذج مرخص ومختبر. التفاصيل في `docs/SPECIALIST_MODEL.md`.

## وظائف غير مكتملة ويجب عدم الادعاء بأنها جاهزة
- **التصنيف المحلي العام:** على iOS يستخدم التطبيق Apple Vision `VNClassifyImageRequest` لتصنيف الصورة على الجهاز دون رفعها للإنترنت. هذه ليست موسوعة متخصصة ولا تحدد النوع العلمي للنبات/الحيوان؛ وقد تكون التسميات عامة أو غير دقيقة. يجب بناء التطبيق الأصلي (EAS development/production build) حتى تتوفر الوحدة الأصلية.
- **التعرف المتخصص على الأنواع:** لم يدمج بعد نموذج مدرّب على أنواع النباتات والحيوانات السعودية. يلزم اختيار نموذج مناسب، والتحقق من ترخيصه، وتوفير ملف النموذج والملصقات واختبار الدقة على مجموعة صور موثقة.
- **الحزم القابلة للتنزيل:** لم تُنشأ حزم بيانات/نماذج إنتاجية أو خدمة تنزيل وتحقق من سلامة الملفات بعد.
- **موسوعة شاملة:** بيانات الأنواع في `src/data/species.ts` أمثلة محدودة وليست مرجعًا شاملًا ولا تغطي جميع الأنواع.
- **الاختبار على أجهزة حقيقية ورفع App Store:** لم يتم تنفيذهما بعد.

## تشغيل المشروع
يتطلب Node.js وnpm واتصالًا لتنزيل الاعتماديات أول مرة:

```bash
npm install
npx expo start
```

جرّب عبر Expo Go حيثما كانت الوحدات مدعومة. وحدة Apple Vision محلية أصلية؛ لذلك لن تعمل داخل Expo Go العام. أنشئ Development Build أو EAS Build بعد ضبط `extra.eas.projectId` في `app.json`.

## ملفات مهمة
- `App.tsx`: الواجهة وتدفق التصوير والسجل.
- `src/data/species.ts`: أمثلة دليل الأنواع.
- `src/data/packs.ts`: بيانات عرض الحزم المخطط لها.
- `src/services/storage.ts`: طبقة SQLite للمفضلة وسجل الاكتشافات.
- `assets/icon-concept.png`: تصور أيقونة التطبيق، وقد تحتاج قصًا/تحسينًا قبل النشر.

## قائمة تحقق قبل النشر
1. اختيار نموذج متخصص محلي مناسب للأنواع وترخيصه وتضمينه واختباره على صور موثقة. تصنيف Apple Vision الحالي عام وليس تحديدًا للنوع.
2. تحديد مقياس دقة وحدود ثقة، وإظهار عدم اليقين وعدم إطلاق اسم نوع عند ضعف النتيجة.
3. جمع بيانات الأنواع من مصادر موثوقة وتوثيق مصادر البيانات وتراخيص الصور والنصوص.
4. بناء نظام حزم حقيقي: تنزيل آمن، تحقق من checksum/signature، مساحة تخزين، إلغاء/استئناف، تحديثات وتراجع.
5. اختبار دون إنترنت فعليًا بعد تثبيت الحزم، واختبار حذف الملفات وانقطاع التنزيل.
6. اختبار TypeScript وExpo Doctor وiOS/Android على أجهزة فعلية، وفحص الاعتماديات والثغرات.
7. إضافة سياسة خصوصية واضحة، ومراجعة أذونات الكاميرا والصور والموقع. التصنيف الحالي لا يرفع الصور، ويجب ألا يضاف رفع سحابي دون موافقة صريحة.
8. ضبط معرّفات التطبيق والأيقونات ولقطات الشاشة والبناء والتوقيع وبيانات App Store Connect.

## تنبيه علمي وسلامة
لا تستخدم هذه النسخة لاتخاذ قرارات تتعلق بسلامة النباتات للأكل أو العلاج، أو الاقتراب من الحيوانات/الزواحف. أسماء الأنواع العامة في الدليل ليست تشخيصًا من صورة.


## نموذج النباتات المحلي
حزم النباتات والحيوانات والطيور تنزّل نماذج Core ML عامة من Hugging Face عند الطلب. يلزم الإنترنت للتنزيل الأول؛ وبعد نجاح التثبيت يعمل الاستدلال محليًا. النماذج ليست مدربة خصيصًا على الحياة البرية السعودية، ونموذج الحيوانات العام لا يتجاوز 8 فئات. راجع `docs/SPECIALIST_MODEL.md` للمصادر والقيود.
